# 产品开发生命周期（蒸馏自 AIPD-OS，供编排时参考）

> 真相源是 AIPD-OS 引擎本身；本文档是模型侧摘要。冲突时以引擎输出与 AIPD 文档为准。

## 生命周期主线

产品定义 → 研究 → 产品手册 → CAD → 工业化 → BOM/成本 → 验证（EVT/DVT/PVT）→ 发布准备。

关键概念：
- **Product Truth**：被门禁冻结的产品定义快照（Snapshot + content hash），提交需 Owner 批准，exactly-once。不要试图绕过门禁"先提交了再说"。
- **事实状态**：V 实测 / S 仿真 / C 计算 / E 外部证据 / A 假设 / P 待供应商 / T 待测试 / R 废弃。呈现结论时保留状态标签——"成本 ¥x（C，计算值）"和"成本 ¥x（V，实测）"是完全不同的声明。
- **成熟度阶梯 C0–C7**：网格模型 → 参数化 CAD → 装配 → CAE → DFM → 图纸包 → 实物证据。CAD 后端的诚实上限（无内核时封顶 C1）是纪律不是缺陷，不要承诺超过当前成熟度的产物。

## 升级决策的时刻（必须问用户）

产品方向选择 / 价值取舍 / 安全法规相关 / 关键接口冻结 / 不可逆投入（开模、下单价）/ 真人试穿试戴 / 量产放行。升级时带结构化决策包：推荐 + 理由 + 2–4 个选项 + 影响 + 证据 + 不确定性 + 未回复时的继续项。

## 制造准备的真实边界（审查在案）

- BOM 成本数据当前靠手工录入（`aipd bom add --unit-cost`），报价→BOM 自动回填链路未打通——呈现成本时注明数据来源；
- 报价管理：登记草稿报价会顶替正式报价（已知问题），操作时留意先确认正式报价状态；
- 外部邮件（RFQ 等）能力未实现，引擎会诚实报"外部依赖"——不要承诺自动发询价邮件；
- 发布物有 Ed25519 签名链，验证发布物完整性走 `aipd release check`，不要凭文件名判断真伪。

## 给模型的编排提示

- AIPD 的 supervisor 有阶段机与工作队列；你可以建议偏离默认阶段顺序，但偏离要让引擎留痕（走它的命令，不要绕过）。
- 门禁未通过（gate not READY）时，呈现差距清单，而不是建议降低标准。
