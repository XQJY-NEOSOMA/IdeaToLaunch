# 产品开发生命周期全本（继承自 AIPD-OS）

> 本文件是完整方法论，IdeaToLaunch 在独立模式下直接按此执行；锚定模式下以 AIPD-OS 引擎的门禁与状态库为准。

## 一、生命周期主线（S0–S8）

| 阶段 | 名称 | 出口标准（不得因文件齐全而跳级） |
|---|---|---|
| S0 | 项目接管 | 产品目标、约束、已知信息全部显性化 |
| S1 | 理论基础与证据 | 场景/用户/动作/环境/替代方案研究完成，至少三条路线比较 |
| S2 | 产品定义与 V1 架构 | 主方案、备选、V1 边界、需求、系统架构、初始 BOM、验证框架 |
| S3 | 产品手册 | 手册链完成（锚点锁定后扩页，独立审核通过） |
| S4 | 工程基线 | 人体/运动/载荷/接口/材料/安全/寿命基线确立 |
| S5 | 参数化 CAD 与生产图纸 | 按 C0–C7 推进（见下） |
| S6 | 工业化与供应链 | 规格、RFQ、供应商候选、DFM/DFA、检验、包装、验证计划 |
| S7 | EVT/DVT/PVT 与实体证据 | 阶段验证真实通过（实体证据不可虚构） |
| S8 | 生产发布与变更维护 | 发布物完整、变更留痕 |

阶段表是**默认模板**：可根据项目实际增删合并，但偏离要显式说明理由并留痕。

## 二、统一产品基线

所有产物共享同一份产品基线（模板见 `templates/product-baseline.md`）：手册、CAD、BOM、规格、测试**不得各自维护冲突参数**。后段变更必须回写上游并传播到所有依赖产物；受影响产物标记"待更新"，重建并复核后才能继续。

## 三、事实状态标签（随结论呈现）

| 标签 | 含义 |
|---|---|
| V | 实测/正式验证 |
| S | 仿真 |
| C | 计算 |
| E | 外部证据 |
| A | 工程假设 |
| P | 待供应商确认 |
| T | 待实体测试 |
| R | 已废弃 |

未运行的仿真、未取得的报价、未完成的测试**不得写成事实**。"成本 ¥x（C）"和"成本 ¥x（V）"是完全不同的声明。

## 四、工程成熟度阶梯（C0–C7）

C0 设计意图 → C1 空间架构/网格模型 → C2 参数化零件 → C3 装配验证 → C4 工程验证（CAE/运动）→ C5 制造定义（DFM/GD&T）→ C6 生产图纸包 → C7 生产放行（实物证据）。

- 工具能力决定成熟度上限：没有参数化 CAD 内核时不得越级宣称工程或生产 CAD（网格/面片最高 C1）；
- 正式生产图纸必须含：模型、总装/零件图、BOM、接口控制、尺寸链、GD&T、材料/工艺、装配、关键特性、检验、版本与变更记录；
- 每一级声明必须有对应证据，"可穿、可打印、可生产、可量产"等声明尤其如此。

## 五、手册链纪律（连续附件场景）

用户连续提供的提示词和附件可能是同一工作流，必须识别为同一任务、恢复其阶段与质量基准，不能拆成孤立任务：

1. 先规划：页数、页任务、锚点、批次、资产计划；
2. 样板先行：封面、原理、至少三页样板，建立视觉规范后再扩页；
3. 每批 2–5 页，输入必须包含上一批完整页面、锚点、事实版本与禁用项；
4. 文件检查通过不等于视觉质量通过——需要独立审核。

## 六、升级决策的时刻（必须问用户）

- 不可兼容的产品架构或目标用户分叉；
- 无法从事实推断的品牌、价值和风险偏好；
- 关键人体—机械接口或产品外形边界准备冻结；
- 安全、法规、真人试穿、功效宣称或知识产权风险；
- 正式发图、开模、采购、签约、实体验证或量产发布；
- 已批准硬约束互相冲突。

升级时必须用结构化决策包：**AI 推荐、理由、2–4 个选项、影响、证据、不确定性、未回复时的继续项、明确回复格式**。

不得因页数细化、检索、批次拆分、普通返工、图表重绘、命名或打包询问用户。

## 七、物理世界边界

可以完成全部数字工作和外部任务管理，但**不能虚构**制造、测试、报价、认证或真人试穿已经发生。正式发图、开模、真人试穿和量产发布必须提交所有者决策包。等待外部输入（报价、样机、测试）时标记"待外部"，同时继续其他独立工作。

## 八、声明门

禁止用单一"全链路完成"。分阶段声明，且只有真实证据满足对应门才可声明：
理论就绪 / 产品定义获批 / 手册链已规划 / 手册锚点锁定 / 手册完成 / 工程模型就绪 / 样机制造就绪 / 可真人试用 / 生产发布就绪。

## 九、制造准备的真实边界（继承审查在案认知）

- 成本数据以手工录入为准；呈现成本时注明来源与币种；
- 报价管理中草稿不得顶替正式报价；
- 自动发询价邮件等外部动作不可承诺；
- 发布物完整性验证走签名/哈希链（锚定模式），不凭文件名判断真伪。
