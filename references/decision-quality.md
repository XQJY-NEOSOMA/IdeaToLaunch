# 决策质量方法论（蒸馏自 Vencertia，供编排时参考）

> 真相源是 Vencertia 引擎本身；本文档是方法论的模型侧摘要。冲突时以引擎输出与 Vencertia 文档为准。

## 判断合同（五段式）

每次决策评估的产出物，五段缺一不可：
1. **当前判断**——现在倾向于哪个选项；
2. **为什么**——支撑判断的证据与信念（可追溯到具体证据）；
3. **最大未知**——最该先搞清楚的事；
4. **下一步**——具体的行动或实验；
5. **什么会改变我的判断**——翻转条件（来自敏感度分析：哪个信念变多少会翻转结论）。

## 证据权威分级（结构性，不可打分抹平）

从低到高：模型先验 < 外部研究 <  reviewed 外部研究 < 创始人陈述 < 项目内实验 < 客户真实付费。
**外部研究永远不能自动升级为本项目事实**——要获得最高权威，必须有本项目内的直接观察/实验/支付行为。

## ABSTAIN 纪律

- 触发：关键不确定性超过阈值、或证据相互冲突未解。
- 输出必须附带：一个可执行的最小实验（有明确验证标准），或"还需要什么证据"清单。
- 呈现 ABSTAIN 时不得美化措辞让它看起来像 GO。

## 校准与台账

- 每个预测先登记（predicted_probability + 信念快照哈希），到期后结算（成真/落空），结算不可逆；改判生成新版本留痕。
- 校准看板：Brier 分数（越低越好）、ECE、分桶命中率。样本不足（默认 <20）时状态为 UNCALIBRATED——此时不要向用户展示任何"校准后"数字。
- 解读校准结果的用途：让用户知道自己"80% 把握"的话历史上到底有几成准。

## 给模型的编排提示

- 呈现判断合同时按五段结构，不要合并省略"什么会改变判断"——那是最有价值的一段。
- 用户录入新证据后，提醒其通过 `outcome-record`/`evidence-add` 走引擎，而不是让你"记在对话里"。
