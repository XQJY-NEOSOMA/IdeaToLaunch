# 市场与用户研究全本

> 本文件为 IdeaToLaunch 内建方法论，独立使用。

本文档规定"从一句话想法到产品落地"中市场与用户研究环节的全部规程。你（AI 主管）在想法验证期按本文件执行，产出的每条结论直接服务于"该不该做"的决策验证，并接入《决策质量方法论》（decision-quality.md）的假设清单与证据分级。

证据状态统一使用四态：**VERIFIED / ESTIMATED / ASSUMED / UNVERIFIED**（定义见 decision-quality.md 第二节）。本文档中所有"证据等级"均指四态之一。

---

## 一、何时做、做什么

### 1.1 触发时机

| 时机 | 研究目标 | 深度 |
|---|---|---|
| 一句话想法刚提出（验证期起点） | 回答"这个需求真实存在吗、市场值得进吗" | 快速桌面研究 + 5-8 个访谈，1-2 周内完成 |
| 做出"做/不做"初判后、进入 MVP 前 | 回答"第一批用户是谁、为什么是他们" | 定向深访 + 可用性观察 |
| MVP 上线后 | 回答"假设哪条被推翻"（转入实验验证，本文件不再主导） | 以行为数据为准 |

### 1.2 研究目标：降低最大未知，不是写报告

想法验证期研究的唯一目的是**降低当前决策的最大未知**。开工前必须先回答三个问题并写下来：

1. 当前"该不该做"判断悬在什么上？（从假设清单里挑出最高杠杆的 UNVERIFIED / ASSUMED 条目）
2. 哪条未知一旦判断错误代价最大？
3. 本次研究能在什么时间内、以什么成本把这条未知降到可承受水平？

**判定研究的完成标准**：不是"报告写完了"，而是"目标假设的状态标签发生了变化"（UNVERIFIED → ESTIMATED 或 VERIFIED），或如实得出"研究后仍无法判断，需要最小实验"。

**禁止事项**：
- 不得做"大而全行业研究报告"式研究——没有对应到具体假设的研究产出一律视为浪费；
- 不得为了支持已有倾向而选择性找证据（确认偏误红线，见第八节）。

## 二、桌面研究规程

### 2.1 信息源分层（可信度从高到低）

| 层级 | 来源 | 默认用途 | 注意事项 |
|---|---|---|---|
| L1 官方统计 | 国家统计局、行业主管部门、上市公司财报/招股书、海关数据 | 市场规模、人口结构、行业总量 | 注意统计口径与年份；财报中的分部收入口径可能与你的产品口径不同 |
| L2 行业报告 | 艾瑞、易观、IDC、Gartner、头豹、券商研报 | 增长率、竞争格局 | 注意出品方利益立场（为谁写的报告）；免费摘要与付费全文结论可能不同 |
| L3 学术论文 | 知网、Google Scholar、SSRN | 行为机制、因果证据 | 看样本与场景是否可迁移到中国市场/本项目 |
| L4 竞品公开信息 | 官网、App Store/应用商店页面、招聘信息、融资公告、创始人访谈 | 竞品功能、定价、团队规模推断 | 官网话术是营销不是事实；招聘信息可推断其技术栈与扩张方向 |
| L5 社区舆情 | 知乎、小红书、即刻、V2EX、Reddit、垂直论坛、应用商店评论 | 用户真实抱怨、需求信号 | 声量≠规模；注意水军与幸存者偏差 |

### 2.2 执行步骤

1. **列检索清单**：针对待验证假设，逐条写下"需要什么数据、最可能在哪一层来源找到"。
2. **逐源检索并留痕**：每取一条数据，当场记录【来源全称 + 链接/出处 + 发布日期 + 数据对应年份】，缺任何一项不得进入结论。
3. **标注时效**：数据发布超过 3 年且所在行业变化快的，降级使用（只能作趋势参考，不能作当前规模依据），并标注"时效存疑"。
4. **交叉验证**：执行 2.3 规则。
5. **录入假设清单**：每条通过交叉验证的数据，以 ESTIMATED 状态录入（外部证据，未在本项目验证，不得标 VERIFIED）。

### 2.3 交叉验证规则（硬性）

- **至少两个相互独立的来源**指向同一结论，该结论才升级为"可用证据"（ESTIMATED）；
- "相互独立"指：不是同一份报告的互相转载、不是同一机构的不同渠道发布、不是 A 引用 B 的链式来源；
- 只有两个同源或来源无法确认独立时，结论保持 UNVERIFIED，并在呈现时写明"单一来源，未交叉验证"；
- 两个来源数字冲突时：不得取平均糊弄，并列呈现两个数字 + 各自口径差异，按 ASSUMED 处理并在后续研究中消解。

## 三、用户研究规程

### 3.1 用户访谈规程

**样本量建议**：
- 探索期：5-8 个目标用户即可发现主要模式（第 5 个之后新增信息通常锐减）；
- 若用户分两到三个明显不同的细分人群，**每类至少 5 个**；
- 受访者必须是真实目标用户或其决策者，不得用"朋友觉得"代替。

**招募标准（先于访谈写死）**：符合目标人群画像 + 近 6 个月内有过相关行为/痛点经历 + 非利益相关方（不是团队成员亲友的友情反馈）。

**问题设计三原则**：
1. **问行为，不问观点**。问"上一次遇到这个问题是什么时候、你当时怎么处理的、花了多少钱/时间"，不问"你觉得这个功能好不好"。过去的行为是证据，对未来的承诺不是。
2. **避免诱导**。禁用句式："你会不会用……""如果有一个产品能……你买吗""你不觉得……很麻烦吗"。改用："你上次做 X 是怎么做的？""这个过程中哪一步最烦？""你现在为此花钱吗？花给谁？"
3. **追问具体数字与场景**：金额、频次、耗时、上一次发生的日期。答不出具体细节的"我很需要"按无效处理。

**访谈流程（每次 30-45 分钟）**：
1. 开场（3 分钟）：说明目的，请求记录许可；
2. 背景与现状行为（10 分钟）：对方现在怎么做这件事；
3. 痛点挖掘（10 分钟）：最近一次完整经历复盘（时间线法）；
4. 现有解决方案与花费（8 分钟）：现在用什么、付多少钱、为什么不满意；
5. 收尾（5 分钟）——**不推销产品**，只问"如果这个问题解决了，你下一步会做什么"；
6. 访谈后 24 小时内整理记录：直接引语 + 行为事实 + 你的推断，三者分开写。

**访谈记录表模板**：

| 字段 | 内容 |
|---|---|
| 受访者编号/画像 | U01，如"二线城市教培机构校长，3 年从业" |
| 招募渠道 | 如"行业社群招募" |
| 关键行为事实 | 可核实的行为与数字（原话引用） |
| 现有解决方案与花费 | 用什么、多少钱、多久一次 |
| 痛点强度信号 | 是否主动提及 / 被问到才说 / 无所谓 |
| 与本项目假设的关系 | 支持 / 削弱 / 无关哪条假设 |
| 证据等级 | 访谈属"用户陈述"，最高记 ESTIMATED |

### 3.2 问卷设计要点

- 问卷用于**量化访谈中已发现的需求模式**，不得用问卷去发现需求（顺序反了会收到一堆礼貌性假阳性）；
- 有效样本量：描述性结论至少 100 份有效回收；做分组对比每组至少 50 份；
- 必设筛选题（开头剔除不符合目标人群的受访者）与测谎题（如反向措辞题）；
- 关键问题必须有行为锚点选项（"过去 3 个月做过几次"），不给"也许会用"这种零成本选项；
- 意愿付费问题用具体价格点选择题（"如果定价 ¥99/月，你会？"），不用开放式"你愿意付多少钱"（答案系统性虚高）；
- 问卷结论整体按"用户陈述"对待，最高记 ESTIMATED；回收渠道必须记录（朋友圈转发的问卷只能代表你的朋友圈）。

### 3.3 可用性观察

- 让用户**实际操作**现有方案或你的原型，你在旁边只观察不指导；
- 记录：卡住点、放弃点、绕过功能的土办法、完成任务的实际步骤数；
- 观察到的行为属"本项目内直接观察"，可记 VERIFIED（仅限"该用户在该场景下做了该行为"这一事实本身，不得外推为"所有用户都会这样"）；
- 样本：5 个用户能发现约 80% 的可用性问题，5-8 个为验证期标准配置。

## 四、需求证据分级（与决策证据权威分级对接）

同样是"需求存在"的论断，证据强度天差地别。按权威从低到高：

| 级别 | 证据形态 | 四态上限 | 能支撑的决策 |
|---|---|---|---|
| 1 | 行业报告/第三方研究说"需求旺盛" | ESTIMATED | 只能支撑"值得继续做研究" |
| 2 | 用户访谈/问卷说"我需要、我会买" | ESTIMATED | 支撑"值得做最小实验" |
| 3 | 用户付出非金钱成本：花时间深谈、参与内测、填写详细反馈、推荐给同事 | ESTIMATED（强） | 支撑 MVP 立项讨论 |
| 4 | 用户在本项目实验中表现出真实行为：留存、复用、主动访问 | VERIFIED | 支撑继续投入 |
| 5 | 用户掏钱：定金、预购、付费、签意向书且不可无条件退款 | VERIFIED | 支撑"做"的判断 |

**操作规则**：
- "用户说想要"（级别 2）永远不得写成"需求已验证"；
- 级别 1-3 的结论必须显式标注"陈述性证据，行为未验证"；
- 只有级别 4-5 能把假设清单中的需求条目升为 VERIFIED；
- 级别 5 中"意向书/口头承诺"若可无条件反悔，降级为级别 3。

## 五、市场规模估算规程（TAM/SAM/SOM）

### 5.1 定义

- **TAM**（总可及市场）：假设产品占据全部适用场景的年度总收入上限；
- **SAM**（可服务市场）：你的产品形态、地域、渠道实际能覆盖的那部分 TAM；
- **SOM**（可获得市场）：3-5 年内凭现实资源能拿下的 SAM 份额。

### 5.2 自顶向下法（从宏观数据往下切）

1. 找 L1/L2 层来源的行业总规模数字（记录来源、年份、口径）；
2. 逐层乘上筛选比例：地域比例 × 目标客群比例 × 付费能力/意愿比例；
3. 每个比例必须有出处或显式标注 ASSUMED；
4. 写出完整算式：TAM = X 亿元（来源A，2023）× 比例 a（来源B）× 比例 b（ASSUMED）。

### 5.3 自底向上法（从单元经济往上垒）

1. 确定目标客群总数：潜在客户数（如"全国 K12 教培机构约 N 万家"，给来源）；
2. 确定单客户年付费（ARPU 假设）：来自访谈中的实际付费行为或竞品定价，标注来源；
3. SOM = 可达客户数 × 渗透率假设 × ARPU；
4. 渗透率假设必须给出类比依据（同品类产品第 3 年渗透率），无依据标 ASSUMED。

### 5.4 双法交叉（硬性）

- **两种方法必须都做**，结果相差在一个数量级以内为通过；
- 相差超过一个数量级：不得取折中，逐项对比两法的假设，找出分歧最大的假设，列为新的 UNVERIFIED 条目并安排验证；
- **所有单位与假设必须显性化**：金额单位（人民币/美元、含税与否）、时间口径（年收入/累计）、每个比例的来源；算式写全，不许只给结论数字；
- **数据不足时，写"数据不足"并说明缺哪一块、建议怎么补（访谈/实验/特定报告）——严禁编造数字填坑**。编造数据是本环节第一红线（见第八节）。

### 5.5 规模估算输出模板

| 项目 | 数值与单位 | 方法 | 关键假设 | 证据等级 | 来源与时效 |
|---|---|---|---|---|---|
| TAM | 例：¥120 亿/年 | 自顶向下 | 行业报告口径含硬件，软件部分按 60% 计（ASSUMED） | ESTIMATED | 《XX 行业白皮书 2024》，艾瑞咨询，2024-03 |
| SAM | … | … | … | … | … |
| SOM（3 年） | … | 自底向上 | 渗透率 2%，类比同品类 Y 产品第 3 年数据 | ASSUMED | Y 产品招股书，2022 |

## 六、输出物规格：研究结论卡

每条研究结论以"研究结论卡"形式产出，禁止写成流水账段落。格式：

```
【研究结论卡】
结论：（一句话，可证伪的陈述）
对应假设：假设清单编号 H-xx
证据等级：VERIFIED / ESTIMATED / ASSUMED / UNVERIFIED
证据类型：桌面研究 / 访谈陈述 / 问卷陈述 / 行为观察 / 实验 / 付费
来源：具体来源全称（访谈给受访者编号，如 U01/U03/U05）
时效：数据年份 + 采集日期
交叉验证：来源 2（独立来源）→ 一致 / 冲突 / 仅单一来源
对决策的影响：支撑 GO / 支撑 NO-GO / 不足以判断，建议最小实验：____
```

**使用规则**：
- 结论卡按证据类型分组呈现，先摆高级别证据；
- 任何进入判断合同（decision-quality.md 五段式）的依据，必须能追溯到一张结论卡；
- 结论卡的"证据等级"与假设清单同步更新，研究结束后假设清单状态必须整体刷新一遍。

## 七、研究的停止条件与升级路径

满足以下任一条件即停止研究，进入决策或实验：
1. 目标假设已升至 ESTIMATED 且有明确的 GO/NO-GO 指向；
2. 继续桌面研究/访谈已无新信息（连续 3 个访谈无新增模式）；
3. 剩余未知只能靠"让用户真实使用/付费"才能解决——此时正确动作是**设计最小实验**（见 decision-quality.md 第四节），不是继续研究。

研究后仍无法判断时，输出 ABSTAIN + 最小实验建议，不得美化成 GO。

## 八、红线（违反任一即本轮研究作废重做）

1. **不得编造数据或来源**：找不到就写"数据不足"；所有来源必须真实可查，引用前确认该来源确实存在且确实说过这句话；
2. **单一来源不升级为事实**：未通过 2.3 交叉验证的结论不得高于 UNVERIFIED（标注 ASSUMED 仅限有明确理由的工程性假设）；
3. **不得把相关性当因果**："做了 X 的用户留存高"不等于"X 导致留存高"；因果论断必须来自本项目实验或明确标注为推断；
4. **不得用确认偏误选证据**：每条结论卡必须同时记录"有没有发现反面证据"，有就必须并列呈现；
5. **不得把用户陈述当行为**：访谈与问卷结论最高 ESTIMATED，且必须带"陈述性证据"标注；
6. **样本不足明说**：访谈 <5 人或问卷 <100 份时，结论卡上标注"样本不足，仅供方向参考"，不得外推比例。
